# Временные ряды: приведение шести рядов к стационарному виду

Домашняя работа по программе Нетологии «Machine learning», модуль «Временные ряды»,
занятие 1. Автор - Евгения Вострецова.

## Что здесь

- `Временные_ряды_общая_теория_(Вострецова_Евгения).ipynb` - работа целиком,
  с уже посчитанными выводами и графиками. Повторный запуск не требуется.
- шесть файлов `.csv` - исходные ряды, лежат рядом с ноутбуком.

## Данные

| Файл | Ряд | Шаг | Точек | Период |
|---|---|---|---|---|
| `monthly-sales-of-company-x-jan-6.csv` | продажи компании X | месяц | 77 | 1965-1971 |
| `monthly-boston-armed-robberies-j.csv` | вооруженные ограбления в Бостоне | месяц | 118 | 1966-1975 |
| `international-airline-passengers.csv` | пассажиры международных авиалиний | месяц | 144 | 1949-1960 |
| `mean-monthly-air-temperature-deg.csv` | средняя месячная температура воздуха | месяц | 240 | 1920-1939 |
| `weekly-closings-of-the-dowjones-.csv` | закрытие индекса Доу-Джонса | неделя | 162 | 1971-1974 |
| `daily-total-female-births-in-cal.csv` | рождения девочек в Калифорнии | день | 365 | 1959 |

## Что сделано

Каждый ряд проверен четырьмя способами сразу - график, метод интервалов,
коррелограмма и расширенный тест Дики-Фуллера - и приведен к стационарному виду.
Набор операций у рядов разный, и выбирался он по замеру, а не по умолчанию.

| Ряд | Преобразование | p-value ADF до | после |
|---|---|---|---|
| Продажи компании X | логарифм - тренд - профиль месяца | 0.9889 | 0.0026 |
| Ограбления в Бостоне | логарифм + разность | 0.7499 | 0.0000 |
| Пассажиры авиалиний | логарифм + сезонная разность + разность | 0.9919 | 0.0000 |
| Температура воздуха | вычитание профиля месяца | 0.0594 | 0.0000 |
| Индекс Доу-Джонса | разность | 0.6225 | 0.0000 |
| Рождения девочек | вычитание тренда и профиля дня недели | 0.0000 | 0.0000 |

Сверх задания в конце два помеченных раздела: встречная проверка тестом KPSS
и замер того, чем платит лишнее дифференцирование.

## Как запустить

Python 3.12, пакеты `pandas`, `numpy`, `matplotlib`, `seaborn`, `scipy`, `statsmodels`.

Ноутбук читает `.csv` по имени файла, поэтому запускать его нужно из этой папки -
там, где лежат сами данные.

```
jupyter notebook "Временные_ряды_общая_теория_(Вострецова_Евгения).ipynb"
```
